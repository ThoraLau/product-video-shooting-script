这是一个面向产品展示型短视频的拍摄脚本生成 Skill。
它不是用来写强剧情、强表演、靠模特情绪感染用户的视频，而是把产品卖点、用户痛点和消费者需要理解的信息，拆成一个个有明确目的的镜头。
核心目标是：让需求方在对接摄影团队前，就已经想清楚每个镜头为什么拍、要传达什么，以及最终画面应该长什么样。
比如一个镜头，不只会写“展示产品防水”，而会进一步明确：拍什么动作 用什么角度 光影怎么处理 镜头是静态还是运镜 画面需要停留几秒 对应字幕说什么 需要什么场地、模特和道具 是否需要参考图 这个镜头最终要让消费者理解哪一个卖点
也就是说，这个 Skill 输出的不是粗略分镜，而是一份可以直接交给摄影团队执行的产品视频拍摄需求文档

它包含的能力
  从产品定位和真实 VOC 中提炼核心卖点
  把专业产品语言翻译成小白用户能理解的生活场景
  将中文情绪母稿转成自然英文口播
  按 Wiggle 风格设计 Hook、节奏和 CTA
  用六维摄影框架判断动作、光影、角度、运镜、景别和画面重点
  为每个卖点匹配最合适的“画面证据”
  识别负面评论风险和过度宣传边界
  为每个镜头补充时长、字幕、参考图、场地、道具等执行信息
  自动输出完整拍摄脚本模板
  同时生成 Markdown + Excel 两种交付文件
  内置标准化 Excel 表头和拍摄脚本结构
  支持 Codex 自动调用，方便后续批量生成和重复使用
